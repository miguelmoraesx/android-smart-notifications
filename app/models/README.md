# Modelos locais

Este diretório documenta o ponto de integração, mas **não versiona pesos de modelos**.

Use na aplicação o botão **Selecionar modelo .litertlm**. O arquivo escolhido é copiado para
`filesDir/models/selected-model.litertlm`, um caminho privado e legível pelo LiteRT-LM.

Arquivos `.litertlm` e `.task` são ignorados pelo Git para evitar commits acidentais de artefatos
grandes ou sujeitos aos termos de distribuição do modelo.
